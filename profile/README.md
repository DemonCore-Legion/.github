# DemonCore

**DemonCore** is an open source server emulator for **World of Warcraft: Legion 7.3.5 (build 26972)**.
This organization is dedicated to Legion emulation: a stable, complete 7.3.5 game world you can run yourself,
with optional modules on top of it.

## Repositories

| Repository | What it is |
| --- | --- |
| [DemonCore](https://github.com/DemonCore-Legion/DemonCore) | The core: world and authentication servers, database, scripts, and a module system |
| [DemonCore-Playerbots](https://github.com/DemonCore-Legion/DemonCore-Playerbots) | Playerbots module: bot players that group with you, run dungeons and battlegrounds, and fill queues |
| [DemonCore-Build](https://github.com/DemonCore-Legion/DemonCore-Build) | GitHub Actions workflow building ready-to-run Windows x64 binaries |

## Status

The project is under active development. Recent work:

- Legion class hall and artifact weapon campaigns for all twelve classes
- Broken Isles zone questlines
- Dungeon and raid fixes
- Playerbots with dungeon finder and battleground support
